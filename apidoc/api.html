🔧 주요 함수들

write(obj, target_path=None, format=None, show_progress=False, verbose=False, **kwargs)

데이터 객체를 안전하게 파일 또는 데이터베이스에 저장합니다.

📋 매개변수:

  • obj: 저장할 데이터 객체 (pandas.DataFrame, polars.DataFrame, np.ndarray)
  • target_path: 파일 저장 경로 (파일 기반 쓰기 시 필수)
  • format: 저장 포맷 ('csv', 'parquet', 'excel', 'json', 'sql', 'database')
  • show_progress: 진행률 표시 여부
  • verbose: 상세한 성능 진단 정보 출력 여부

💡 기본 사용법:

# 기본 파일 저장
import atio
import pandas as pd

# 샘플 데이터 생성
df = pd.DataFrame({
    "name": ["Alice", "Bob", "Charlie"],
    "age": [25, 30, 35],
    "city": ["Seoul", "Busan", "Incheon"]
})

# 다양한 포맷으로 저장
atio.write(df, "users.parquet", format="parquet")
atio.write(df, "users.csv", format="csv", index=False)
atio.write(df, "users.xlsx", format="excel", sheet_name="Users")
atio.write(df, "users.json", format="json", orient="records")

🗄️ 데이터베이스 저장:

# SQL 데이터베이스 저장 (Pandas)
from sqlalchemy import create_engine

engine = create_engine('postgresql://user:password@localhost/dbname')
atio.write(df, format="sql", name="users", con=engine, if_exists="replace")
# 데이터베이스 저장 (Polars)
import polars as pl

polars_df = pl.DataFrame({
    "product_id": [101, 102, 103],
    "product_name": ["Laptop", "Mouse", "Keyboard"],
    "price": [1200, 25, 75]
})

atio.write(polars_df, format="database", 
          table_name="products", 
          connection_uri="postgresql://user:password@localhost/dbname")

write_snapshot(obj, table_path, mode='overwrite', format='arrow', show_progress=False, **kwargs)

데이터 객체를 열 단위 청크로 분해하여 버전 관리 방식으로 저장합니다.

📋 매개변수:

  • obj: 저장할 데이터 객체
  • table_path: 테이블 데이터가 저장될 최상위 디렉토리 경로
  • mode: 'overwrite' (기본값) 또는 'append'
  • format: 내부 청크 파일 포맷 (현재는 'arrow'만 지원)

💡 스냅샷 저장 예시:

# 1. 초기 스냅샷 저장
df_v1 = pd.DataFrame({
    'product': ['Laptop', 'Mouse', 'Keyboard'],
    'price': [1000, 20, 50],
    'stock': [10, 100, 50]
})

atio.write_snapshot(df_v1, "products", mode='overwrite')
print("버전 1 저장 완료")

# 2. 업데이트된 스냅샷 저장
df_v2 = df_v1.copy()
df_v2.loc[0, 'price'] = 1200  # Laptop 가격 상승
df_v2.loc[1, 'stock'] = 80       # Mouse 재고 감소

atio.write_snapshot(df_v2, "products", mode='overwrite')
print("버전 2 저장 완료")

read_table(table_path, version=None, output_as='pandas')

지정된 버전의 스냅샷을 읽어 데이터 객체로 재구성합니다.

📋 매개변수:

  • table_path: 테이블 데이터가 저장된 최상위 디렉토리 경로
  • version: 불러올 버전 ID (None이면 최신 버전)
  • output_as: 반환할 데이터 객체 타입 ('pandas', 'polars', 'arrow', 'numpy')

💡 테이블 읽기 예시:

# 1. 최신 데이터 읽기
latest_data = atio.read_table("products", output_as="pandas")
print("최신 데이터:")
print(latest_data)

# 2. 특정 버전 읽기
v1_data = atio.read_table("products", version="v1", output_as="pandas")
print("\\n버전 1 데이터:")
print(v1_data)

# 3. Polars로 읽기
polars_data = atio.read_table("products", output_as="polars")
print("\\nPolars 데이터:")
print(polars_data)

write_model_snapshot(model, model_path, metadata=None, **kwargs)

머신러닝 모델을 안전하게 저장합니다.

💡 모델 저장 예시:

import joblib
from sklearn.ensemble import RandomForestClassifier

# 모델 생성
model = RandomForestClassifier(n_estimators=100)
model.fit(X_train, y_train)

# 모델 저장
metadata = {
    'model_type': 'RandomForest',
    'n_estimators': 100,
    'accuracy': 0.95
}

atio.write_model_snapshot(model, "my_model", metadata=metadata)
print("모델 저장 완료")

read_model_snapshot(model_path, version=None)

# 예측 수행
predictions = loaded_model.predict(X_test)

delete_version(table_path, version)

지정된 버전의 스냅샷을 삭제합니다.

💡 버전 삭제 예시:

# 특정 버전 삭제
atio.delete_version("products", "v1")
print("버전 v1 삭제 완료")

rollback(table_path, target_version)

테이블을 지정된 버전으로 롤백합니다.

💡 롤백 예시:

# 버전 v1으로 롤백
atio.rollback("products", "v1")
print("버전 v1으로 롤백 완료")

# 롤백 후 데이터 확인
rolled_back_data = atio.read_table("products")
print("롤백된 데이터:")
print(rolled_back_data)
