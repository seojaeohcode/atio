🔒 Atio 라이브러리 문서

안전한 원자적 파일 쓰기를 위한 Python 라이브러리

API 문서 핵심 기능 플러그인 시스템 유틸리티 성능 보고서 실행 예시

📖 라이브러리 소개

Atio는 Pandas, Polars, NumPy 등 다양한 데이터 객체를 안전하게 파일로 저장할 수 있는 Python 라이브러리입니다.

🔒 원자적 쓰기

데이터 손실을 방지하는 안전한 파일 쓰기 방식으로, 시스템 중단 시에도 데이터 무결성을 보장합니다.

📸 스냅샷 시스템

대용량 데이터를 효율적으로 저장하고 버전을 관리하는 고급 저장 시스템입니다.

🚀 고성능

병렬 처리와 최적화된 알고리즘으로 빠른 데이터 처리를 제공합니다.

⚡ 주요 기능

  • 원자적 쓰기: 시스템 중단 시에도 안전한 데이터 저장
  • 스냅샷 관리: 버전별 데이터 저장 및 복구
  • 다양한 포맷 지원: CSV, Parquet, Excel, JSON, SQL 등
  • 병렬 처리: 멀티스레드를 활용한 고성능 처리
  • 진행률 표시: 실시간 처리 상황 모니터링
  • 자동 롤백: 실패 시 이전 상태로 자동 복구

📦 설치 방법

pip install atio

💡 빠른 시작

import atio
import pandas as pd

# 데이터 생성
df = pd.DataFrame({'name': ['Alice', 'Bob'], 'age': [25, 30]})

# 안전한 저장
atio.write(df, 'data.parquet', format='parquet')
